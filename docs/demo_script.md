# Demo Flow

1. Start the API.
2. Open `http://localhost:8000`.
3. Confirm the system health pill is `System OK`.
4. Choose a synthetic victim.
5. Review interaction history and trend.
6. Inspect model metrics.
7. Use `/docs` for API calls.
8. Run `POST /predict` for a synthetic interaction.
9. Observe the predicted distress, risk level, trend and SHAP contributors.
10. Confirm high/critical predictions appear in the human review queue.

All records in the included demo dataset are synthetic.
